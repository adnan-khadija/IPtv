# 📺 StreamVault — Premium IPTV Service

> A modern, bilingual (EN/FR) IPTV subscription website built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+
- npm v9+

### Installation

```bash
# 1. Navigate to the project folder
cd streamvault

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 💳 Subscription Plans

All plans are for **1 device / 1 screen**. Prices are in **CHF**.

| Plan ID   | Duration  | Promo Price | Normal Price |
|-----------|-----------|-------------|--------------|
| `1m-1s`   | 1 Month   | 14 CHF      | 18 CHF       |
| `3m-1s`   | 3 Months  | 35 CHF      | 45 CHF       |
| `6m-1s`   | 6 Months  | 55 CHF      | 75 CHF       |
| `12m-1s`  | 12 Months | 79 CHF      | 130 CHF      |

### How plan selection works

1. User clicks a plan on the **Pricing** section → redirected to `/[lang]/checkout?plan=Xm-1s`
2. The checkout page reads the `?plan=` URL param via `useSearchParams()`
3. `getPlanFromParam(param)` from `src/lib/data/plans.ts` resolves it to the correct `Plan` object
4. All prices, durations, and labels on the checkout / payment / confirmation screens are rendered **dynamically** from that plan object

```ts
// src/lib/data/plans.ts
export function getPlanFromParam(param: string | null): Plan {
  if (!param) return plans[0];
  return plans.find((p) => p.id === param) ?? plans[0];
}
```

> ⚠️ **Important:** The plan IDs in `plans.ts` must exactly match the `?plan=` values generated by `Pricing.tsx`. Current format: `Xm-1s` (e.g. `6m-1s`).

## 🌐 Bilingual Support (EN / FR)

| Language | URL prefix | Content source            |
|----------|------------|---------------------------|
| English  | `/en/...`  | `src/lib/content/en.ts`   |
| French   | `/fr/...`  | `src/lib/content/fr.ts`   |

To edit any text, update the corresponding content file. Both checkout pages also have inline French translations for labels, buttons, and form fields.

## 🔧 Customization

### Update prices

Prices live in **two places** — keep them in sync:

```ts
// 1. src/lib/data/plans.ts  (used by checkout pages)
{ id: "12m-1s", price: 79, originalPrice: 130 }

// 2. src/lib/content/en.ts  (used by the Pricing section on the homepage)
prices: { "12": { normal: 130, promo: 79 } }
```

### Add / edit FAQ, features, or testimonials

Edit the relevant file in `src/lib/data/` — the components read from these files directly.

### Clear Next.js build cache (if changes don't appear)

Stop the dev server, delete the `.next` folder, then restart:

```bash
# Windows PowerShell
Remove-Item -Recurse -Force .next
npm run dev
```
